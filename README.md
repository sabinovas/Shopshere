# ShopSphere

An end-to-end retail lakehouse on **Azure Databricks**, built over eight weeks as a portfolio project.
It takes the Kaggle [Olist Brazilian e-commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
plus a synthetic clickstream from raw files to dashboards, ML models, a RAG assistant and a Databricks App,
with everything deployed from this repo. The plan and schedule are in [PLAN.md](PLAN.md).

## Architecture

```
Azure SQL (Olist) ──JDBC──────┐
ADLS landing (JSON/CSV) ─Auto Loader─┤
Event Hubs (Faker clicks) ─Kafka─────┤
Policy PDFs (volume) ─ai_parse_document┘
                │
                ▼  Unity Catalog: shopsphere_dev
 BRONZE raw_* ──► SILVER (Lakeflow Declarative Pipeline) ──► GOLD star schema (materialized views)
                  AUTO CDC: customers SCD2, orders upsert       fact_sales (liquid clustered), 5 dims
                  expectations + quarantine, sessions           KPIs, RFM, product performance, funnel
                │                                               metric views: sales_metrics, funnel_metrics
                ├─► ML: feature table → AutoML + XGBoost/Optuna → UC registry (@champion/@challenger)
                │       → nightly batch scoring → Lakehouse Monitoring (drift); Prophet demand forecast
                ├─► GenAI: AI functions on tickets → knowledge base → Vector Search → tool-calling agent
                │       (Agent Framework, MLflow evaluation) → serving endpoint → Databricks App
                └─► AI/BI dashboards (executive, FinOps) · Genie space · Delta Sharing share

Orchestration: Lakeflow Job (bronze → pipeline → quality checks → dashboard, churn features → scoring)
Deployment:    Databricks Asset Bundle (dev/test/prod) · GitHub Actions · Terraform for Azure + UC
```

## Tech stack

| Area | What's used |
|---|---|
| Azure | ADLS Gen2, Access Connector (managed identity), Premium Databricks workspace, Key Vault, Azure SQL, Event Hubs (Kafka), budget alerts |
| Governance | Unity Catalog: catalog per environment, external locations, Key Vault secret scope, volumes, lineage; grants, column masks and row filters written in [`src/governance`](src/governance) |
| Ingestion | Auto Loader (schema evolution, rescued data), JDBC, Structured Streaming from Event Hubs with watermarks, session windows and checkpoint recovery |
| Transformation | Lakeflow Declarative Pipelines: AUTO CDC from snapshot (SCD1/SCD2), expectations (warn/drop/fail), quarantine, materialized views, liquid clustering; Delta MERGE, deletion vectors, time travel, Change Data Feed, OPTIMIZE/VACUUM |
| BI | Serverless SQL warehouse, metric views, AI/BI dashboards, Genie |
| ML | Feature engineering in UC, AutoML, XGBoost + Optuna, MLflow, UC model aliases, Model Serving, Lakehouse Monitoring, Prophet |
| GenAI | `ai_translate`, `ai_analyze_sentiment`, `ai_classify`, `ai_parse_document`, `ai_query` embeddings, Vector Search, MLflow ChatAgent with tools, MLflow GenAI judges, Agent Framework, Databricks Apps (Streamlit, on-behalf-of-user auth) |
| Ops | Asset Bundles, GitHub Actions (ruff, pytest, bundle validate, gated deploys), Terraform, cluster policy, system-table FinOps dashboard, Photon benchmark |

## Running it

```bash
pip install -r requirements-dev.txt
ruff check . && pytest -q                       # lint and unit tests

export DATABRICKS_HOST=https://<workspace>.azuredatabricks.net
databricks bundle validate                      # dev by default; -t test / -t prod
databricks bundle deploy
databricks bundle run shopsphere_daily          # bronze → pipeline → checks → scoring → dashboard
```

The Azure resources and Unity Catalog objects come first (Terraform in [`infra/terraform`](infra/terraform)),
then the Olist CSVs are loaded into Azure SQL with [`src/ingestion/load_olist_to_sql.py`](src/ingestion/load_olist_to_sql.py).

## Results

| Area | Result |
|---|---|
| Bronze | All counts match the source (for example 99,441 orders, 112,650 order items) |
| Data quality | 22 expectations; quarantine catches bad orders; SCD2 history verified after source changes |
| Clickstream | Checkpoint recovery: stopped mid-stream and restarted with every event exactly once |
| Churn model | Holdout ROC AUC 0.58: about 99% of Olist customers never order again, so the signal is weak (reported as is) |
| Demand forecast | 8-week backtest WAPE 14–57% across the top 8 categories |
| RAG assistant | MLflow judges on 8 questions: correctness 1.00, relevance 1.00, safety 1.00, citations 0.63 |
| Photon | 3.2× faster on 30M-row joins, aggregations and windows (49.9 s → 15.8 s on one 4-core node) |
| Cost | About $68 of Databricks list cost in October, 81% of it from a Vector Search endpoint left running; the FinOps dashboard is what surfaced it |

## Notes

- The policy PDFs and the clickstream are synthetic and labelled as such; review comments stand in for support tickets.
- Claude models were not enabled for this workspace, so the assistant runs on Llama 4 Maverick.
- The workspace's regional quota is 4 cores, so every job runs on one single-node cluster.
